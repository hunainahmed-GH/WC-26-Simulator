# ⚽ FIFA World Cup 2026 Simulator

An AI-powered FIFA World Cup 2026 tournament simulator built using React, Vite, Recharts, and machine learning inspired prediction logic.

# 📌 Features

- Full FIFA World Cup 2026 Group Stage Simulation
- Dynamic Knockout Bracket System
- AI-style Match Prediction Engine
- Player Analytics Dashboard
- Interactive Charts & Visualizations
- Historical FIFA World Cup Statistics
- Golden Boot & Awards Simulation
- K-Means Player Clustering
- Responsive Neon UI Design

# 🧠 Machine Learning Concepts Used

## 1. K-Means Clustering
Used to categorize players into:
- Goal Poachers
- Creative Playmakers
- Dribbling Specialists
- Defensive Players
- Box-to-Box Midfielders

### Features used:
- Goals per 90
- Assists per 90
- Key Passes
- Dribbles
- Tackles

## 2. Sigmoid Probability Function
Used to calculate:
- Win Probability
- Draw Probability
- Loss Probability

Based on FIFA ranking differences.

## 3. Statistical Simulation
Tournament outcomes are generated using probability-based random simulation logic.
